# Paper scripts

This directory contains the experiment and evaluation drivers used by the paper. The scripts under scripts/ evaluate learned checkpoints, the network-free physics anchor, classical planners, OOD scenarios, and stress settings.

The paper figure-generation, visualization, and result-presentation Python scripts are intentionally omitted from this release. Generated figures, checkpoints, and per-episode result files are also excluded.

Campaign launchers are under campaigns/. Configure PEVA_REPO, PEVA_DATA_ROOT, and PY before using them.
